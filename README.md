# 균형 정원: 새벽의 꽃축제
중1 등식과 방정식에서 출발한 9단계 자원 전략 게임입니다. 양쪽에 같은 연산을 적용해 x = 수를 만들고 꽃을 피웁니다. 모든 화단이 제한된 도구와 물을 공유합니다. 급한 꽃의 순서, 제한 시간을 늘리는 물, 양변에 1씩 더하는 가시와 덮개를 함께 판단합니다. 되돌리기·재도전과 별·개화 보상이 있습니다.

`npm test`, `npm run build`, `npm start`로 독립 실행합니다. Vercel에서 이 저장소를 Import하면 `vercel.json`의 정적 빌드 설정을 사용합니다. 실제 배포 URL은 아직 등록되지 않았습니다.

## 학습 확인
`assessment/`는 [9수02-03]에 맞춘 식의 분류, 대입 확인, 양변의 동일 연산 과정, 0으로 나누기와 해 보존 조건을 새 문항에서 확인합니다. 첫 답·오답·도움·재시도와 학생 설명, 교사 검토 기록을 기기에 익명 저장하고 JSON/인쇄로 내보냅니다. 교사 검토는 인증 기능이 없는 관찰 기록입니다. 게임 점수·승리나 표본 과제 성공을 공식 이수 판정으로 삼지 않습니다. 기록을 다른 학습자와 공유하지 않으려면 학습 확인 화면에서 새 학습자를 선택하세요.

## 출처와 에셋
`sources.json`, `assessment.json`에 단원·쪽·성취기준 및 범위를 기록했습니다. 교과서 PDF, 추출 원문 및 렌더 이미지는 포함하지 않습니다. 주요 그래픽은 내장 image_gen으로 생성한 3개 이미지이며 프롬프트는 `assets/prompts.json`에 있습니다. 배경, 정원사, 저울·물 자원·가시·꽃 보상을 실제 게임에 사용합니다. 수식은 코드로 표시합니다. Jua / Do Hyeon / Gowun Dodum WOFF2와 원래 라이선스를 `theme/`에 포함합니다.

## 검증
`tests/`는 모든 정원의 독립 해 대입 검증과 승리 경로, 초기 전략이 실패하는 반례, 도구 소모, 물·시간·보호 선택, 0 나눗셈, 평가의 오답·도움·재시도·설명 대기를 확인합니다. 실제 브라우저 확인 결과는 `evidence/browser-review.json`에 기록합니다. 실제 학생에게 재미나 학습 효과를 검증한 것은 아닙니다.
